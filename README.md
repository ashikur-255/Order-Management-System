# Order Management System

## Overview
This is a comprehensive Order Management System built to handle order processing, inventory tracking, and customer data seamlessly. Developed with **ASP.NET Core** and **SQL Server**, this application provides a secure, high-performance, and scalable solution for managing business operations.<br>

## Key Features
* **Order Processing:** Create, update, and track the status of customer orders efficiently.
* **Inventory Management:** Monitor stock levels, add new items, and manage product catalogs.
* **Customer Management:** Maintain detailed records of customers and their transaction histories.
* **Secure Database:** Robust data management and relational structuring using SQL Server and Entity Framework Core.
* **Dashboard Analytics:** Quick overview of total sales, pending orders, and active inventory.

## Technologies Used
* **Backend:** ASP.NET Core, C#
* **Database:** Microsoft SQL Server, Entity Framework Core (EF Core)
* **Frontend:** HTML5, CSS3, JavaScript (Razor Pages / MVC)
